# Snapshots

This folder will contain pre-generated PNG snapshots of the climate map for each taxon, named by slug:

```
dionaea-muscipula-typical.png
drosera-capensis-narrow-leaf.png
...
```

These are generated by `scripts/generate-snapshots.js` using Playwright. Each snapshot captures the map in embed mode (`?taxon={id}&embed=true`) at 600×420px and saves it here.

Once generated, these PNGs will be embedded on individual taxon pages in the Bogman Gallery.

**This is a future phase — snapshots are not yet generated.**
